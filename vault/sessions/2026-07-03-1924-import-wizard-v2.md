# Import Wizard v2 (Excel/CSV) — three-step wizard + existing-board import

## What changed

- Full brainstorm -> spec (`docs/superpowers/specs/2026-07-03-import-wizard-v2-design.md`) ->
  plan (`docs/superpowers/plans/2026-07-03-import-wizard-v2.md`) -> subagent-driven build of a
  16-task plan, each task individually reviewed. Branch `task/import-wizard-v2` pushed to origin
  (16 commits, `49caf6a` head). **Not merged to develop yet.**
- Replaced the v1 `ImportDialog` with a three-step `ImportWizard` (Upload -> Select & Map ->
  Confirm): dropzone, multi-sheet tabs, header-row picker, per-column include/rename/kind/role
  controls, per-row exclusion, invalid-cell highlighting, typed confirm preview + honest summary.
  Detection now also infers percent/currency/email/link/dropdown.
- M2: import into an **existing board** — file columns auto-matched to board columns
  (`match-columns.ts`), commit via a new transactional RPC `import_rows_into_board`
  (`supabase/migrations/20260703110000_...sql`), BoardHeader "Import" entry (viewer-gated).
- Whole-branch review found + fixed a **critical board-level privilege-escalation** (RPC lacked
  the `can_edit_board` guard that every other definer write-RPC has) plus 5 correctness/honesty
  fixes (fix commit `49caf6a`). Re-review: **READY TO MERGE**. All 4 gates green
  (typecheck / lint / test 2111 passed / build).

## Why

The v1 import was a bare type-map dialog: no column/row selection, no mapping to an existing board,
no real preview — the exact gaps the user called out. v2 makes import a first-class, safe flow in
both directions (new board + append), matching the board-level RLS security model.

## How to test (for the user)

Once merged and the migration is re-applied (see Open threads), `pnpm dev`:

1. New board: sidebar **New board -> Import from file** -> drag an `.xlsx`/`.csv`. Pick a sheet,
   set the header row, include/rename columns, set one as the item name, exclude a junk row ->
   **Next** -> typed preview + summary -> **Create board** -> lands on the new board.
2. Existing board: open a board (as editor) -> header **Import** -> upload a file -> each column
   auto-matches to a board column (or Create new / Skip) -> pick a target group -> **Import** ->
   rows appended into that group.
3. Security check: as a **viewer** on a board, the header **Import** button must not appear; the
   RPC rejects a viewer/cross-org caller with a not-authorized error.
